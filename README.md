# Bookstore Backend

## Overview

This project is a Node.js backend for a bookstore application, built using the Express.js framework. It manages users, books, authors, toplists, wishlists, coupons, and gift cards. The database is powered by MariaDB, and JSON Web Tokens (JWT) are used for authorization.

## Technologies

- **Backend Framework**: Express.js
- **Database**: MariaDB
- **Authorization**: JWT (JSON Web Tokens)
- **ORM**: Sequelize
- **Other Dependencies**: bcrypt, CORS, dotenv, Joi
